# 🗃️ 小型数据库应用

## 🧩 全章概览

### 🎯 项目目标与定位
- 构建轻量级数据管理能力：支持单机或局域网环境下的结构化数据存储与查询
- 面向教学与原型验证：强调可理解性、可调试性与工程规范性
- 技术栈可控性原则：选用成熟、易部署、低依赖的数据库技术（如 SQLite / MySQL Lite / 嵌入式 H2）

### 📚 核心知识模块
- 数据库设计基础  
  - 需求分析与实体识别  
  - E-R 模型构建与关系转化  
  - 范式化设计（1NF–3NF）与反范式权衡
- SQL 实践能力  
  - DDL：CREATE TABLE / ALTER / DROP  
  - DML：INSERT / UPDATE / DELETE / SELECT（含 JOIN、GROUP BY、子查询）  
  - DCL：权限控制基础（GRANT / REVOKE，若适用）
- 应用集成开发  
  - 数据访问层封装（JDBC / SQLAlchemy / PDO 等）  
  - CRUD 接口设计与实现  
  - 事务管理与异常处理机制

### ⚙️ 典型技术栈组合
- 存储层  
  - SQLite：零配置、文件型、ACID 兼容，适合桌面/嵌入式场景  
  - MySQL / PostgreSQL（精简部署）：支持多用户、网络访问与高级特性  
- 应用层  
  - Python + Flask/Django ORM  
  - Java + Spring Boot + JPA/Hibernate  
  - Node.js + Express + Sequelize/Knex
- 展示层  
  - 命令行交互界面（CLI）  
  - 简易 Web 界面（HTML+JS+后端模板）  
  - 可视化数据看板（Chart.js / ECharts 基础集成）

## 🛠️ 实施路径与阶段划分

### 🌱 阶段一：环境准备与建模
- 安装并验证数据库引擎（含命令行工具）
- 绘制业务领域 E-R 图（含主外键标注）
- 编写建表 SQL 脚本并执行初始化

### 🧱 阶段二：功能模块开发
- 用户管理模块：注册/登录/权限分级（可选）
- 核心业务表增删改查接口（含输入校验）
- 查询增强：模糊搜索、分页、排序、条件组合

### 🧪 阶段三：测试与优化
- 单元测试覆盖关键 SQL 逻辑（如 DAO 层）
- 边界测试：空值、超长输入、非法操作
- 性能初检：索引添加建议（EXPLAIN 分析）
