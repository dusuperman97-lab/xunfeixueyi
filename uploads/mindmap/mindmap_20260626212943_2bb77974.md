# 🧠 人工智能导论与学习准备

## 📘 全章概览

### 🔍 核心定位与目标
- 定义人工智能：模拟、延伸和扩展人类智能的理论、方法、技术及应用系统
- 学习目标：建立AI认知框架，掌握基础术语与演进脉络，明确学习路径与工具准备
- 适用人群：零基础入门者、转行学习者、跨领域研究者

### 📚 知识结构全景
- 三大知识支柱  
  - 基础理论：数学（线性代数、概率统计、微积分）、逻辑与计算理论
  - 技术主线：机器学习 → 深度学习 → 大模型与生成式AI
  - 工程支撑：Python编程、数据处理（NumPy/Pandas）、开发环境（Jupyter/Colab）

### ⚙️ 学习准备清单
- 开发环境配置  
  - Python 3.8+ 及常用科学计算库安装
  - IDE选择：VS Code（轻量高效）或 PyCharm（功能全面）
  - 云平台入门：Google Colab（免费GPU）、Kaggle Notebooks
- 数据素养培养  
  - 数据获取：公开数据集（UCI、Kaggle、天池）
  - 数据理解：结构化 vs 非结构化；标注数据与无监督数据
- 学习节奏建议  
  - 阶段式推进：概念理解 → 动手实践 → 项目复现 → 原理深挖
  - 每日投入：≥1小时有效学习（含代码实操+笔记整理）

## 🌐 AI发展脉络与关键里程碑

### 📅 历史演进阶段
- 符号主义时代（1950s–1980s）  
  - 逻辑推理与专家系统主导
  - 代表成果：ELIZA、MYCIN
- 连接主义崛起（1980s–2000s）  
  - 神经网络复兴：反向传播算法、CNN雏形
  - 算力与数据瓶颈制约规模化应用
- 深度学习爆发期（2012–今）  
  - AlexNet突破 → ImageNet竞赛推动算力-算法协同进化
  - Transformer架构（2017）→ 大语言模型（LLM）范式革命

### 🏗️ 当前技术生态图谱
- 应用层：智能客服、AIGC、自动驾驶、医疗影像分析
- 框架层：PyTorch（研究首选）、TensorFlow（工业部署）、JAX（高性能科研）
- 基础设施层：GPU集群、AI芯片（NPU/TPU）、分布式训练框架（DeepSpeed/FSDP）
