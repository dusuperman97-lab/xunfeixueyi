# 🌐 RagGraph 基础与核心原理

## 🧠 全章概览

### 🔍 核心概念定义  
- RagGraph：一种融合检索增强生成（RAG）与图神经网络（GNN）的新型知识推理架构  
- 检索增强生成（RAG）：通过外部知识库动态检索相关信息，提升大语言模型（LLM）的事实准确性与可解释性  
- 图结构表示：将文档片段、实体、关系建模为节点与边，支持语义关联与路径推理  

### ⚙️ 架构组成模块  
- 检索子系统  
  - 多粒度分块策略：按段落、句子、实体层级切分文本  
  - 向量+关键词混合检索：兼顾语义相似性与精确匹配  
- 图构建引擎  
  - 节点生成：文档块、关键实体、用户查询作为基础节点  
  - 边构建：基于共现、语义相似度、引用关系动态加权连接  
- 图推理层  
  - 图神经网络编码器：聚合邻居信息，生成上下文感知节点表征  
  - 查询导向图注意力机制：聚焦与当前问题最相关的子图路径  
- 生成融合模块  
  - 检索证据注入：将图中高相关节点内容拼接为提示上下文  
  - 一致性校验机制：对比生成答案与图中逻辑路径的一致性  

### 📈 关键技术优势  
- 可解释性增强  
  - 支持溯源：每条生成答案可回溯至图中对应节点与边  
  - 可视化推理路径：提供从查询→检索→图传播→生成的完整链路  
- 动态知识更新  
  - 增量图构建：新文档仅需新增节点与局部边，无需重训全局模型  
  - 版本化图快照：支持知识状态回滚与A/B实验对比  
- 多跳推理能力  
  - 跨文档关联：通过图连接不同来源的碎片化知识  
  - 隐式关系挖掘：利用GNN自动发现未显式标注的间接关联
