# 🧠 人工智能导论与学习准备

## 📘 全章概览

### 🌐 学科定位与价值
- 人工智能（AI）定义：模拟、延伸和扩展人类智能的理论、方法、技术及应用系统
- 学科交叉性：融合计算机科学、数学、认知科学、语言学与神经科学
- 社会驱动力：算力跃升、数据爆炸、算法突破共同推动AI规模化落地

### 📚 核心知识模块
- 基础理论层  
  - 符号主义：基于逻辑推理与规则系统（如专家系统）
  - 连接主义：以神经网络为代表，强调学习与自适应能力
  - 行为主义：关注智能体与环境交互（强化学习基础）
- 技术能力层  
  - 机器学习：监督/无监督/半监督/强化学习范式
  - 深度学习：CNN、RNN、Transformer等主流架构演进
  - 自然语言处理与计算机视觉：典型应用领域与任务边界
- 工程实践层  
  - 开发环境搭建：Python生态、Jupyter、Anaconda、GPU驱动配置
  - 主流框架入门：TensorFlow / PyTorch 基础对比与选型建议
  - 数据准备规范：采集、清洗、标注、增强全流程要点

### 🛠️ 学习路径准备
- 数学基础要求  
  - 线性代数：矩阵运算、特征值与奇异值分解
  - 概率统计：贝叶斯定理、分布建模、假设检验
  - 微积分：梯度、链式法则、优化目标函数求导
- 编程能力储备  
  - Python核心语法：列表推导、函数式编程、面向对象设计
  - 科学计算库：NumPy（数组操作）、Pandas（数据处理）、Matplotlib（可视化）
  - 工具链协同：Git版本管理、VS Code调试、Docker容器化初识
- 学习资源策略  
  - 理论优先：经典教材（如《Pattern Recognition and Machine Learning》）
  - 实践驱动：Kaggle竞赛、开源项目复现、Colab实战笔记
  - 社区共建：GitHub跟踪前沿模型、Stack Overflow解疑、中文技术社区（如知乎、掘金）
