# 🧠 人工智能导论与学习准备

## 📘 全章概览

### 🌐 学科定位与价值
- 人工智能（AI）定义：模拟、延伸和扩展人类智能的理论、方法、技术及应用系统
- 学科交叉性：融合计算机科学、数学、认知科学、神经科学与哲学
- 现实意义：驱动产业升级、提升社会效率、重塑人机协作范式

### 📚 核心知识脉络
- 基础层：数学基础（线性代数、概率统计、微积分）、编程能力（Python为主）
- 方法层：机器学习、深度学习、自然语言处理、计算机视觉、强化学习
- 应用层：智能推荐、自动驾驶、医疗辅助、工业质检、语音交互

### 🛠️ 学习准备体系
- 工具环境搭建
  - Python开发环境（Anaconda/Miniconda + Jupyter）
  - 深度学习框架（PyTorch/TensorFlow）
  - 版本控制（Git）与协作平台（GitHub）
- 学习路径规划
  - 入门→进阶→项目实战三级跃迁
  - 理论学习与代码实践同步推进
  - 持续复现经典论文与开源项目
- 资源生态构建
  - 经典教材（如《机器学习》周志华、《深度学习》花书）
  - 在线课程（Coursera、Fast.ai、李沐《动手学深度学习》）
  - 社区与论坛（Stack Overflow、知乎、Reddit r/MachineLearning）
