# 🌟 Spring Boot 核心原理与项目搭建

## 🧩 全章概览  
### 🔍 核心定位与价值  
- 快速开发框架：基于Spring生态的约定优于配置（Convention over Configuration）理念，极大简化Spring应用初始化与配置  
- 自动化配置引擎：通过`spring-boot-autoconfigure`模块实现条件化自动装配Bean，减少XML/JavaConfig手动声明  
- 内嵌容器支持：默认集成Tomcat、Jetty或Undertow，无需部署WAR至外部Servlet容器  

### ⚙️ 核心原理体系  
- 启动机制（SpringApplication）  
  - `SpringApplication.run()`入口触发事件驱动生命周期  
  - `ApplicationContextInitializer`、`ApplicationRunner`等扩展点介入时机  
- 条件化装配（@Conditional）  
  - `@ConditionalOnClass`、`@ConditionalOnMissingBean`等注解控制Bean注册逻辑  
  - `AutoConfigurationImportSelector`动态加载`META-INF/spring.factories`中定义的自动配置类  
- Starter依赖机制  
  - 命名规范：`spring-boot-starter-xxx`统一管理依赖版本与传递依赖  
  - 模块化封装：如`spring-boot-starter-web`自动引入Spring MVC + Tomcat + Jackson  

### 🛠️ 项目搭建流程  
- 初始化方式选择  
  - Spring Initializr（Web/IDE插件/CLI）生成基础骨架  
  - 手动构建Maven/Gradle工程并引入`spring-boot-starter-parent`父POM  
- 关键结构组成  
  - 主启动类：含`@SpringBootApplication`注解（组合`@Configuration`+`@EnableAutoConfiguration`+`@ComponentScan`）  
  - `application.yml`/`application.properties`：外部化配置中心，支持多环境（dev/test/prod）profiles切换  
- 构建与运行  
  - `mvn spring-boot:run`热启动调试  
  - `mvn clean package`生成可执行fat-jar，内置`org.springframework.boot.loader.JarLauncher`

## 🎯 进阶延伸方向  
### 🌐 生态整合  
- 与Spring Cloud协同：服务注册发现（Nacos/Eureka）、配置中心（Config Server/Apollo）、网关（Gateway）  
- 云原生适配：Kubernetes Deployment YAML编写、Liveness/Readiness Probe健康检查配置  

### 🧪 工程实践强化  
- 生产就绪特性（Actuator端点监控、Metrics指标采集、HTTP Trace日志追踪）  
- 多模块聚合构建（parent-pom + module-service/module-api/module-dao分层治理）

- `SpringApplication.prepareEnvironment()`：环境抽象（Environment）与PropertySource加载顺序  
- `AutoConfigurationImportSelector.selectImports()`：条件过滤与自动配置类排序（@AutoConfigureOrder）
