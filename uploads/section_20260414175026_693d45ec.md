# Flask API服务封装

## 一、核心知识讲解

### 1.1 Flask简介

*   **定义**：Flask是一个用Python编写的轻量级Web应用框架，它提供了一个简单而灵活的方式来创建Web应用程序。
*   **特点**：易于上手，扩展性强，支持RESTful架构。

### 1.2 RESTful API设计原则

*   **无状态**：每个请求都应包含服务器处理所需的所有信息，客户端与服务器之间的交互是无状态的。
*   **资源导向**：将数据和操作视为资源，通过URL来定位资源。
*   **统一接口**：使用标准的HTTP方法（GET, POST, PUT, DELETE等）对资源进行操作。

### 1.3 Flask中创建API

*   **安装Flask**：首先需要在项目环境中安装Flask库。
*   **初始化应用**：创建一个Flask应用实例，并设置路由和视图函数。
*   **返回JSON响应**：利用Flask提供的`jsonify`函数可以方便地返回JSON格式的数据。

## 二、详细示例 / 案例分析

### 2.1 使用Flask构建一个简单的API服务

*   **示例点1**：环境准备

确保你的开发环境中已经安装了Python和pip工具。接着，可以通过pip安装Flask。

```bash
pip install flask
```

*   **示例点2**：编写代码

下面是一个简单的例子，展示了如何使用Flask创建一个基本的API服务。

```python
from flask import Flask, jsonify, request

app = Flask(__name__)

# 定义一个简单的路由
@app.route('/api/data', methods=['GET'])
def get_data():
    # 假设这里从数据库获取数据
    data = {'message': 'Hello, World!'}
    return jsonify(data)

if __name__ == '__main__':
    app.run(debug=True)
```

*   **示例点3**：运行服务

保存上述代码为`app.py`文件后，在命令行中运行`python app.py`即可启动服务。访问`http://localhost:5000/api/data`可以看到返回的消息。
