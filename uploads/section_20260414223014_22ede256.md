# Spring MVC与RESTful API

## 一、核心知识讲解

### 1.1 Spring MVC概述

*   **Spring MVC**：Spring MVC是Spring框架的一部分，它提供了一个模型-视图-控制器（MVC）架构，用于开发灵活且松耦合的Web应用程序。
*   **主要组件**：DispatcherServlet、Controller、Model、View等。

### 1.2 RESTful API概念

*   **REST**：Representational State Transfer，一种设计风格，用于构建轻量级和可扩展的Web服务。
*   **资源**：REST中的关键概念，可以是任何信息或数据，如用户、订单等。
*   **操作**：通过HTTP方法（GET、POST、PUT、DELETE等）对资源进行操作。

### 1.3 创建RESTful API

*   **注解**：使用`@RestController`和`@RequestMapping`等注解来定义RESTful API。
*   **请求映射**：通过`@GetMapping`、`@PostMapping`、`@PutMapping`、`@DeleteMapping`等注解来处理不同类型的HTTP请求。

## 二、详细示例 / 案例分析

### 2.1 创建一个简单的RESTful API

假设我们需要创建一个简单的RESTful API来管理用户信息。

1. 添加依赖：在`pom.xml`中添加Spring Web依赖。

```xml
<dependency>
    <groupId>org.springframework.boot</groupId>
    <artifactId>spring-boot-starter-web</artifactId>
</dependency>
```

2. 创建用户实体类：

```java
public class User {
    private Long id;
    private String name;
    private String email;
    // Getters and Setters
}
```

3. 创建用户控制器：

```java
@RestController
@RequestMapping("/users")
public class UserController {

    @GetMapping
    public List<User> getAllUsers() {
        // 返回所有用户列表
    }

    @PostMapping
    public User createUser(@RequestBody User user) {
        // 创建新用户并返回
    }

    @GetMapping("/{id}")
    public User getUserById(@PathVariable Long id) {
        // 根据ID获取用户
    }

    @PutMapping("/{id}")
    public User updateUser(@PathVariable Long id, @RequestBody User userDetails) {
        // 更新用户信息
    }

    @DeleteMapping("/{id}")
    public void deleteUser(@PathVariable Long id) {
        // 删除用户
    }
}
```

### 2.2 测试API

*   使用Postman或其他工具测试上述API。
*   确保每个端点都能正常工作。
