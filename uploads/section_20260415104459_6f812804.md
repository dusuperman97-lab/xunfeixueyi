# 有理数

## 一、核心知识讲解

### 1.1 有理数的定义

*   **定义**：有理数是可以表示为两个整数之比（分数形式）的数，其中分母不为零。

*   **示例**：1/2, -3/4, 7/1 等都是有理数。

### 1.2 有理数的分类

*   **整数**：包括正整数、负整数和零。例如：-2, 0, 5。

*   **分数**：可以写成两个整数比的形式。例如：1/3, -2/5。

### 1.3 有理数的性质

*   **加法封闭性**：任意两个有理数相加的结果仍然是有理数。

*   **乘法封闭性**：任意两个有理数相乘的结果仍然是有理数。

*   **存在逆元**：对于每个非零有理数 a，存在一个有理数 b 使得 a * b = 1。

*   **有序性**：有理数集是有序的，即对于任意两个有理数 a 和 b，总能比较出 a < b 或 a > b 或 a = b。

## 二、详细示例 / 案例分析

### 2.1 有理数的加法

*   **示例点1**：计算 1/2 + 1/3。

```java
// Java代码示例
public class RationalAddition {
    public static void main(String[] args) {
        int numerator1 = 1;
        int denominator1 = 2;
        int numerator2 = 1;
        int denominator2 = 3;

        // 计算通分后的分母
        int commonDenominator = denominator1 * denominator2;
        int newNumerator1 = numerator1 * denominator2;
        int newNumerator2 = numerator2 * denominator1;

        // 相加
        int resultNumerator = newNumerator1 + newNumerator2;
        System.out.println("结果: " + resultNumerator + "/" + commonDenominator);
    }
}
```

*   **示例点2**：计算 -1/4 + 3/8。

