# Python科学计算库NumPy

## 一、核心知识讲解

### 1.1 NumPy简介

*   **数组对象**：NumPy的核心是ndarray（n-dimensional array object），它是一系列同类型数据的集合，以一个固定的维度排列。

*   **高效处理**：由于NumPy数组在内部采用连续存储方式，所以在执行数学运算时比原生Python列表要快得多。

*   **广播功能**：广播允许不同形状的数组进行算术运算，通过扩展较小的数组来匹配较大数组的形状。

*   **矢量化**：NumPy操作可以同时应用于整个数组而无需循环，这称为矢量化。矢量化代码通常更简洁，也更容易理解。

### 1.2 创建NumPy数组

*   **从列表创建**：使用`numpy.array()`函数可以直接将Python列表转换为NumPy数组。

*   **特殊数组**：`numpy.zeros()`、`numpy.ones()`和`numpy.empty()`分别用来创建全0、全1和未初始化的数组。

*   **arange与linspace**：`numpy.arange()`类似于Python的内置`range`函数，但返回的是NumPy数组；`numpy.linspace()`用于生成等间隔的数值序列。

*   **reshape**：`numpy.reshape()`函数可以改变现有数组的形状而不改变其数据。

## 二、示例 / 案例分析

### 2.1 使用NumPy进行基本数学运算

*   **加法**：两个相同形状的数组可以直接相加。

```python
import numpy as np
a = np.array([1, 2, 3])
b = np.array([4, 5, 6])
c = a + b
print(c)  # 输出 [5 7 9]
```

*   **乘法**：数组与标量或另一个数组相乘也是直接支持的。

```python
d = 2 * a
print(d)  # 输出 [2 4 6]
```

*   **矩阵乘法**：对于二维数组，可以使用`numpy.dot()`来计算矩阵乘积。

```python
A = np.array([[1, 2], [3, 4]])
B = np.array([[5, 6], [7, 8]])
C = np.dot(A, B)
print(C)  # 输出 [[19 22] [43 50]]
```
