# PyTorch环境安装与配置

## 一、核心知识讲解

### 1.1 安装PyTorch

*   **选择版本**：根据你的Python版本和CUDA版本选择合适的PyTorch版本。

*   **安装方式**：使用pip或conda进行安装，推荐使用conda以确保依赖项的正确性。

*   **官方文档**：参考官方文档获取最新的安装指南和命令。

### 1.2 配置环境变量

*   **设置路径**：如果需要，为PyTorch相关的库设置环境变量，以便在系统中能够找到它们。

*   **检查安装**：通过运行简单的PyTorch代码来验证安装是否成功。

## 二、示例 / 案例分析

### 2.1 示例说明

*   **要点**：展示如何在Python环境中安装PyTorch，并编写一段测试代码来确认安装无误。

```java
import torch
print(torch.__version__)  // 输出PyTorch版本号

tensor = torch.rand(3, 3)
print(tensor)  // 创建一个随机张量并打印
```
