# DNA结构与复制

## 一、核心知识讲解

### 1.1 DNA的化学组成

*   **脱氧核糖**：是DNA分子中的五碳糖，每个脱氧核糖通过磷酸二酯键连接一个磷酸基团和一个含氮碱基。

*   **含氮碱基**：有四种类型，分别是腺嘌呤（A）、鸟嘌呤（G）、胞嘧啶（C）和胸腺嘧啶（T），它们通过氢键配对形成碱基对。

*   **磷酸基团**：位于DNA分子的外侧，形成了DNA的骨架。

### 1.2 DNA的双螺旋结构

*   **沃森-克里克模型**：由詹姆斯·沃森和弗朗西斯·克里克在1953年提出，描述了DNA分子的双螺旋结构。两条多核苷酸链以反向平行的方式相互缠绕。

*   **碱基互补配对**：A与T之间形成两个氢键，C与G之间形成三个氢键。这种特定的配对方式保证了遗传信息的准确传递。

*   **主链方向性**：一条链的方向是从5'端到3'端，另一条链则相反，从3'端到5'端。

## 二、现状分析 / 应用实践

### 2.1 DNA复制机制

*   **半保留复制**：在细胞分裂前，DNA会进行复制，每个新生成的DNA分子都包含了一条原始的母链和一条新合成的子链。

*   **复制起始点**：DNA复制始于特定的序列，称为复制起点（oriC）。在此处，DNA双链被解开，形成复制叉。

*   **DNA聚合酶的作用**：DNA聚合酶负责将游离的脱氧核苷酸按照模板链上的碱基顺序添加到正在生长的新链上。

*   **前导链与滞后链**：

```plaintext
前导链连续合成，而滞后链则是不连续地合成多个冈崎片段后，再由DNA连接酶将其连成完整的链。
```

### 2.2 生物技术应用

*   **基因工程**：科学家利用限制性内切酶和连接酶等工具，可以在体外切割和重组DNA片段，从而构建出新的生物体或产生有用的蛋白质。

*   **PCR技术**：聚合酶链式反应是一种快速扩增特定DNA片段的技术，广泛应用于法医鉴定、疾病诊断等领域。

*   **基因编辑**：CRISPR-Cas9系统使得精确修改生物体内的基因成为可能，为遗传病治疗开辟了新的途径。
