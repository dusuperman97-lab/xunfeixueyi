# DNA结构与复制

## 一、核心知识讲解

### 1.1 DNA的化学组成

*   **脱氧核糖**：构成DNA的基本单元之一，是一种五碳糖。
*   **磷酸基团**：与脱氧核糖相连，形成DNA的骨架部分。
*   **含氮碱基**：包括腺嘌呤（A）、鸟嘌呤（G）、胞嘧啶（C）和胸腺嘧啶（T），它们通过氢键配对形成碱基对，是遗传信息的载体。

### 1.2 DNA双螺旋结构

*   **双链反向平行**：两条长链以相反方向并行排列，一条链的方向是从5'端到3'端，另一条则是从3'端到5'端。
*   **碱基互补配对原则**：腺嘌呤总是与胸腺嘧啶配对，而鸟嘌呤则与胞嘧啶配对。这种特定的配对方式保证了DNA复制时的信息准确传递。
*   **右手螺旋**：整个分子呈现一个右旋的梯形结构，每旋转一圈包含大约10个碱基对。

## 二、现状分析/应用实践

### 2.1 DNA复制过程

*   **解旋酶的作用**：在DNA复制开始前，首先需要解开双螺旋结构，这一步由解旋酶完成。
*   **单链结合蛋白**：当双链分离后，为了防止它们重新结合，会有一系列的单链结合蛋白附着在暴露出来的单链上。
*   **引物合成**：RNA引物是由引物酶催化生成的小段RNA序列，它为DNA聚合酶提供了一个起始点。
*   **DNA聚合酶的功能**：负责将新的核苷酸按照模板链上的碱基顺序添加到生长中的DNA链末端。
*   **连接酶的作用**：最后，DNA连接酶会把新合成的片段之间存在的小缺口封闭起来，形成完整的DNA链。

*   **半保留复制**：每个新形成的DNA分子都保留了一条原始的母链和一条新合成的子链，这种方式被称为半保留复制。

```java
public class DNAReplication {
    public static void main(String[] args) {
        String templateStrand = "ATCGTACGTA";
        String complementaryStrand = generateComplementary(templateStrand);
        System.out.println("Template Strand: " + templateStrand);
        System.out.println("Complementary Strand: " + complementaryStrand);
    }

    private static String generateComplementary(String strand) {
        StringBuilder complement = new StringBuilder();
        for (char base : strand.toCharArray()) {
            switch (base) {
                case 'A':
                    complement.append('T');
                    break;
                case 'T':
                    complement.append('A');
                    break;
                case 'C':
                    complement.append('G');
                    break;
                case 'G':
                    complement.append('C');
                    break;
                default:
                    throw new IllegalArgumentException("Invalid base: " + base);
            }
        }
        return complement.toString();
    }
}
```
