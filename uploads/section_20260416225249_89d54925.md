# DNA结构与复制

## 一、核心知识讲解

### 1.1 DNA的双螺旋结构

*   **碱基配对**：在DNA分子中，腺嘌呤（A）总是与胸腺嘧啶（T）通过两个氢键相连，鸟嘌呤（G）总是与胞嘧啶（C）通过三个氢键相连。这种特定的配对方式保证了DNA复制时信息传递的准确性。

*   **反向平行**：DNA的两条链是反向平行的，一条链的方向是从5'到3'，而另一条链的方向则是从3'到5'。

*   **磷酸骨架**：DNA分子的外部是由磷酸和脱氧核糖交替排列形成的长链，这条长链构成了DNA的骨干。

*   **遗传信息**：DNA内部的碱基序列编码了生物体所有必需的遗传信息，这些信息指导着蛋白质合成的过程。

## 二、现状分析

### 2.1 DNA复制机制

*   **半保留复制**：当细胞分裂时，DNA进行复制。每个新生成的DNA分子都包含一个原始的旧链和一个完全新合成的链，这种方式被称为半保留复制。

*   **复制起点**：DNA复制开始于特定的位置，称为复制起点或oriC，在这里DNA双链被解开，形成复制叉。

*   **酶的作用**：多种酶参与了DNA复制过程，包括解旋酶（解开双链）、单链结合蛋白（稳定单链）、DNA聚合酶（合成新的互补链）等。

*   **精确校对**：DNA聚合酶具有校对功能，能够识别并修正错误的碱基配对，确保复制的高度准确性。

```python
# 示例代码 - 简化的DNA复制模拟
original_dna = 'ATCGTAGCCTAG'
complement_dna = ''.join([{'A': 'T', 'T': 'A', 'C': 'G', 'G': 'C'}[base] for base in original_dna])
print(f'Original: {original_dna}')
print(f'Complement: {complement_dna}')
```
