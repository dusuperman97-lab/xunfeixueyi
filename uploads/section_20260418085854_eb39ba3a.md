# DNA结构与复制

## 一、核心知识讲解

### 1.1 DNA的化学组成

*   **磷酸**：构成DNA分子骨架的主要成分之一，与脱氧核糖交替连接形成链状结构。

*   **脱氧核糖**：五碳糖的一种，与磷酸基团共同构成DNA分子的主链。

*   **碱基**：包括腺嘌呤（A）、鸟嘌呤（G）、胞嘧啶（C）和胸腺嘧啶（T），它们通过氢键配对形成碱基对，A与T之间形成两个氢键，而C与G之间形成三个氢键。

## 二、现状分析

### 2.1 DNA复制过程

*   **半保留复制**：在细胞分裂时，每个新生成的DNA分子都由一条原始母链和一条新合成的子链组成。这种复制方式确保了遗传信息能够准确无误地传递给下一代。

*   **复制起点**：DNA复制从特定的位置开始，这个位置被称为复制起点或起始点，在这里双链被解开，以便聚合酶可以沿着模板链合成新的互补链。

*   **解旋酶的作用**：在复制过程中，解旋酶负责将双螺旋结构的DNA两条链分开，为后续的复制提供单链模板。

```python
# 示例代码：模拟DNA序列的半保留复制
original_dna = 'ATCGTAGC'
complement_dna = ''.join([{'A':'T','T':'A','C':'G','G':'C'}[base] for base in original_dna])
print(f'原始DNA: {original_dna}')
print(f'互补链: {complement_dna}')
```
