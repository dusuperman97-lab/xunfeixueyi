# Pandas数据处理与分析

## 一、核心知识讲解

### 1.1 Pandas简介

*   **Pandas**：是一个强大的Python数据分析库，提供了大量能够快速便捷地处理结构化数据的函数和数据结构。
*   **DataFrame**：是Pandas中最重要的数据结构之一，它是一种二维表格型的数据结构，可以存储多种类型的数据（包括整数、字符串、浮点数等）。
*   **Series**：是一维数组，可以保存任何数据类型（整数、字符串、浮点数、Python对象等），并且这些数据类型不必相同。

## 二、现状分析 / 应用实践

### 2.1 数据清洗

*   **缺失值处理**：Pandas提供了`dropna`和`fillna`方法来处理缺失值。前者用于删除含有空值的行或列，后者则用来填充空值。
*   **重复数据处理**：使用`drop_duplicates`方法可以轻松移除重复的数据项。

### 2.2 数据转换

*   **数据类型转换**：利用`astype`方法将某一列的数据类型转换为指定类型。
*   **应用函数**：通过`apply`方法可以对数据集中的每个元素执行自定义函数。

```python
import pandas as pd
data = {'Name': ['John', 'Anna'], 'Age': [28, 22]}
df = pd.DataFrame(data)
print(df)
```
