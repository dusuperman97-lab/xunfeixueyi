# 神经网络基础与感知机

## 一、核心知识讲解

### 1.1 神经元模型

*   **生物神经元**：生物神经元是神经系统的基本单元，具有接收信号、处理信号和传递信号的功能。人工神经网络中的神经元模型就是模拟了生物神经元的这一特性。

*   **人工神经元**：在人工神经网络中，一个神经元会接受来自其他神经元的输入，并根据一定的激活函数计算出输出值。这些输出值可以作为下一层神经元的输入。

*   **激活函数**：激活函数用于决定神经元是否被激活。常见的激活函数包括Sigmoid函数、ReLU函数等。它们的作用是为神经网络引入非线性因素，使得模型能够学习到更复杂的模式。

## 二、发展现状 / 应用分析

### 2.1 技术层面

*   **多层感知机（MLP）**：通过将多个感知机构成多层结构，形成了多层感知机。这种结构允许神经网络学习更加复杂的映射关系，从而解决非线性的分类和回归问题。

*   **反向传播算法**：这是训练多层神经网络的一种重要方法，它利用梯度下降法来最小化损失函数。反向传播算法通过从输出层开始，逐层向前计算误差梯度，进而调整权重以优化网络性能。

*   **应用领域**：神经网络已广泛应用于图像识别、自然语言处理、语音识别等多个领域。随着深度学习技术的发展，神经网络在处理复杂任务时展现出了强大的能力。

```python
# 示例代码：使用Python定义一个简单的单层感知机
import numpy as np

def sigmoid(x):
    return 1 / (1 + np.exp(-x))

class Perceptron:
    def __init__(self, input_size, learning_rate=0.1):
        self.weights = np.zeros(input_size + 1)  # +1 for bias
        self.learning_rate = learning_rate

    def predict(self, inputs):
        summation = np.dot(inputs, self.weights[1:]) + self.weights[0]  # w·x + b
        return sigmoid(summation)

    def train(self, training_inputs, labels, epochs=100):
        for _ in range(epochs):
            for inputs, label in zip(training_inputs, labels):
                prediction = self.predict(inputs)
                error = label - prediction
                self.weights[1:] += self.learning_rate * error * inputs
                self.weights[0] += self.learning_rate * error  # update bias

# 创建一个感知机实例并进行训练
perceptron = Perceptron(2)
training_inputs = np.array([[0, 0], [0, 1], [1, 0], [1, 1]])
labels = np.array([0, 0, 0, 1])  # AND gate
perceptron.train(training_inputs, labels)
print('Weights after training:', perceptron.weights)
```
