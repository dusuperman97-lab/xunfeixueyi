# 激活函数与反向传播

## 一、核心知识讲解

### 1.1 激活函数概述

*   **定义**：激活函数是在神经网络中引入的一种非线性变换，用于决定一个神经元是否应该被激活。
*   **常见类型**：Sigmoid, ReLU, Tanh等。其中，ReLU（Rectified Linear Unit）是目前使用最广泛的激活函数之一。
*   **作用**：解决了线性模型的局限性，使得神经网络能够学习和表示复杂的函数。

### 1.2 反向传播算法

*   **原理**：反向传播是一种用于训练人工神经网络的监督学习方法，通过计算损失函数对网络权重的梯度来更新权重。
*   **过程**：首先进行前向传播得到预测值，然后根据真实值与预测值之间的差距计算损失；接着从输出层到输入层逐层计算梯度，并利用梯度下降法更新权重。
*   **重要性**：它是深度学习中实现高效训练的关键技术之一。

## 二、现状分析 / 应用实践

### 2.1 技术层面

*   **优化**：随着研究深入，出现了许多针对特定问题设计的新型激活函数，如Leaky ReLU、PReLU等，这些函数在一定程度上解决了传统激活函数存在的问题。
*   **应用**：反向传播算法结合了高效的激活函数，在图像识别、自然语言处理等领域取得了显著成就。

### 2.2 发展趋势

*   **自适应学习率**：为了解决梯度消失或爆炸的问题，研究者们提出了自适应学习率的方法，如Adam、RMSprop等。
*   **轻量化模型**：为了满足移动设备等资源受限环境的需求，轻量级神经网络架构成为研究热点，如何在保证性能的同时减少模型大小成为一个重要的研究方向。

```python
# 示例代码 - 使用ReLU激活函数
import numpy as np

def relu(x):
    return np.maximum(0, x)

x = np.array([-1, 2, -3, 4])
y = relu(x)
print(y)  # 输出: [0 2 0 4]
```
