# 优化算法与正则化

## 一、核心知识讲解

### 1.1 梯度下降法

*   **梯度下降**：是一种常用的优化算法，用于最小化损失函数。它通过迭代地调整模型参数来寻找使损失函数达到最小值的参数组合。

*   **批量梯度下降（Batch Gradient Descent）**：在每次迭代中使用整个训练集的数据来计算梯度，然后更新权重。这种方法计算成本较高，但可以保证收敛到全局最优解。

*   **随机梯度下降（Stochastic Gradient Descent, SGD）**：每次迭代仅使用一个样本点来计算梯度并更新权重。这种方法速度快，但容易出现较大的波动，可能无法收敛到全局最优解。

*   **小批量梯度下降（Mini-batch Gradient Descent）**：结合了批量梯度下降和随机梯度下降的优点，在每次迭代中使用一小部分数据（称为mini-batch）来计算梯度。这种方法既提高了计算效率，又保持了一定的稳定性。

## 二、发展现状 / 应用分析

### 2.1 正则化技术

*   **L1正则化**：通过向损失函数添加所有权重绝对值之和来惩罚模型复杂度，有助于产生稀疏模型，即只有少数特征被选择。

*   **L2正则化**：通过向损失函数添加所有权重平方和来惩罚模型复杂度，有助于减少过拟合，提高模型泛化能力。

*   **Dropout**：一种在训练过程中随机丢弃一定比例神经元的方法，以防止过拟合。这相当于对模型进行了集成学习，增加了模型的鲁棒性。

```python
# 示例代码：使用PyTorch实现L2正则化
import torch
from torch import nn, optim

class Net(nn.Module):
    def __init__(self):
        super(Net, self).__init__()
        self.fc = nn.Linear(10, 1)

    def forward(self, x):
        return self.fc(x)

model = Net()
loss_fn = nn.MSELoss()
optimizer = optim.SGD(model.parameters(), lr=0.01, weight_decay=1e-5)  # L2正则化的权重衰减系数
```
