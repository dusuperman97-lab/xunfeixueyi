# 数据分类与回归方法

## 一、核心知识讲解

### 1.1 数据分类方法

*   **决策树**：是一种基本的分类与回归算法，它通过递归地将数据集划分为不同的子集来构建模型。每个内部节点表示一个属性上的测试，每个分支代表一个测试结果，每个叶节点存放一个类别。

*   **支持向量机 (SVM)**：是一种监督学习方法，用于分类和回归分析。SVM 的目标是找到一个超平面，使得两个类别的间隔最大化。

*   **K近邻 (KNN)**：是一个基于实例的学习方法，新样本的输出由其最近的k个邻居决定。KNN可以用于分类也可以用于回归。

*   **逻辑回归**：虽然名字中带有“回归”，但逻辑回归实际上是一种分类算法。它使用最大似然估计来预测二分类问题的概率。

### 1.2 回归方法

*   **线性回归**：是最简单的回归形式之一，它假设自变量和因变量之间存在线性关系，并尝试拟合一条直线以最小化残差平方和。

*   **多项式回归**：当数据之间的关系不是线性的而是曲线时，可以使用多项式回归。它通过增加特征的高次项来扩展线性模型。

*   **岭回归**：是一种专为解决多重共线性问题而设计的回归方法。它通过添加正则化项来惩罚系数的大小，从而减少模型的复杂度。

*   **Lasso回归**：类似于岭回归，但Lasso回归不仅能够处理多重共线性问题，还能够进行特征选择，因为它会将一些不重要的特征系数压缩到零。

## 二、现状分析 / 应用实践

### 2.1 技术层面

*   **集成学习**：随着机器学习的发展，集成学习技术如随机森林、梯度提升机等被广泛应用于提高分类与回归任务的性能。

*   **深度学习**：近年来，深度神经网络在图像识别、自然语言处理等领域取得了巨大成功，它们也被用来解决复杂的分类与回归问题。

*   **自动化机器学习 (AutoML)**：AutoML工具允许用户自动选择最佳模型和参数，降低了应用这些技术的门槛。

### 2.2 应用领域

*   **金融**：在信用评分、欺诈检测等场景中广泛应用。

*   **医疗健康**：疾病诊断、药物研发等方向。

*   **电子商务**：推荐系统、客户行为预测等。

*   **物联网**：设备故障预测、能耗优化等。

```python
# 示例代码 - 线性回归
from sklearn.linear_model import LinearRegression
import numpy as np

# 创建简单数据集
X = np.array([[1], [2], [3], [4]])
y = np.array([2, 4, 6, 8])

# 训练模型
model = LinearRegression()
model.fit(X, y)

# 预测
print(model.predict(np.array([[5]])))
```
