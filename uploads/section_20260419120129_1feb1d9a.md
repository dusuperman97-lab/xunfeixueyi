# 生物电信号采集

## 一、核心知识讲解

### 1.1 生物电信号的定义

*   **定义**：生物电信号是指从生物体（如人体）中获取的电活动信号，包括心电图（ECG）、脑电图（EEG）、肌电图（EMG）等。

*   **特点**：这些信号反映了生物体内部生理状态的变化，具有非平稳性、低信噪比等特点。

### 1.2 信号采集原理

*   **传感器**：使用适当的电极或传感器放置在皮肤表面或体内特定位置来捕捉电信号。

*   **放大与滤波**：通过前置放大器对微弱的生物电信号进行放大，并利用滤波器去除噪声干扰。

*   **模数转换**：将模拟信号转换成数字信号以便于计算机处理和分析。

## 二、现状分析

### 2.1 技术层面

*   **高精度传感器**：随着材料科学的发展，现在可以制造出更加灵敏且舒适的传感器，提高信号采集的质量。

*   **无线传输技术**：现代生物电信号采集系统越来越多地采用无线方式传输数据，方便了移动监测。

### 2.2 应用实践

*   **医疗健康**：生物电信号广泛应用于临床诊断、疾病治疗以及个人健康管理领域。

*   **科研探索**：研究人员利用生物电信号开展神经科学、运动医学等多个领域的研究工作。

import numpy as np
from scipy.signal import butter, lfilter

def butter_bandpass(lowcut, highcut, fs, order=5):
    nyq = 0.5 * fs
    low = lowcut / nyq
    high = highcut / nyq
    b, a = butter(order, [low, high], btype='band')
    return b, a

def process_ecg_signal(signal, lowcut, highcut, fs, order=5):
    b, a = butter_bandpass(lowcut, highcut, fs, order=order)
    y = lfilter(b, a, signal)
    return y
