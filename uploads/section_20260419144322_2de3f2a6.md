# 类与对象

## 一、核心知识讲解

### 1.1 面向对象编程概述

*   **面向对象编程**：将现实世界中的事物抽象为程序中的类和对象，通过它们之间的关系实现程序逻辑。
*   **类（Class）**：是对象的抽象模板，定义了对象的属性和行为。它通过`class`关键字来定义。
*   **对象（Object）**：是类的具体实例，具有实际的属性和行为。对象通过`new`关键字实例化。

## 二、现状分析 / 应用实践

### 2.1 技术层面

*   **封装性**：类将数据和操作封装在一起，隐藏内部实现细节，提供对外接口。
*   **继承性**：子类可以继承父类的属性和方法，提高代码复用性。
*   **多态性**：允许不同类的对象对同一消息做出响应，实现灵活的代码设计。

### 2.2 实际应用

*   **GUI开发**：图形用户界面中，按钮、文本框等控件都是类的实例，通过事件处理机制实现交互。
*   **游戏开发**：游戏角色、道具等元素通常使用面向对象的方式来组织和管理。
*   **企业级应用**：如ERP系统中，客户、订单等实体均采用面向对象的方式建模，便于维护和扩展。

```java
// 示例代码 - 创建一个简单的Person类
public class Person {
    private String name;
    private int age;

    public Person(String name, int age) {
        this.name = name;
        this.age = age;
    }

    public void introduce() {
        System.out.println("Hello, my name is " + name + " and I am " + age + " years old.");
    }
}

// 创建Person对象并调用方法
Person person = new Person("张三", 25);
person.introduce();
```
