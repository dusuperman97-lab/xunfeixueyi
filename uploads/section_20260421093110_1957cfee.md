# 流程控制语句

## 一、核心知识讲解

### 1.1 条件语句

*   **if 语句**：用于基于不同条件执行不同的代码路径。

*   **switch 语句**：提供了一种更清晰的方式来处理多分支的条件逻辑。

## 二、发展现状 / 应用分析

### 2.1 技术层面

*   **循环结构**：如 for 循环和 while 循环，是实现重复任务的基础。它们允许我们多次执行一段代码直到满足特定条件为止。

*   **break 和 continue**：提供了跳出循环或跳过当前循环迭代的功能，使程序更加灵活。

```java
public class ControlFlowExample {
    public static void main(String[] args) {
        int number = 10;
        if (number > 5) {
            System.out.println("Number is greater than 5");
        } else {
            System.out.println("Number is less or equal to 5");
        }
    }
}
```
