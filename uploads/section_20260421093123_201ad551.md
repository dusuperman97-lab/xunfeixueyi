# 流程控制语句

## 一、核心知识讲解

### 1.1 条件语句

*   **if 语句**：用于基于条件执行代码。如果指定的条件为真，则执行 if 块中的代码；否则，跳过该块。

*   **switch 语句**：用于选择多个代码块之一来执行。根据表达式的值匹配 case 标签，并执行相应的代码块。

## 二、发展现状 / 应用分析

### 2.1 循环语句

*   **for 循环**：提供了一种重复执行代码的方式，直到满足特定条件为止。它通常用于遍历数组或集合。

*   **while 循环**：当指定的条件为真时，循环会一直执行。在进入循环之前先检查条件。

*   **do-while 循环**：与 while 类似，但至少会执行一次循环体，因为条件是在循环体之后检查的。

```java
// 示例 for 循环
for (int i = 0; i < 5; i++) {
    System.out.println("i = " + i);
}

// 示例 while 循环
int j = 0;
while (j < 5) {
    System.out.println("j = " + j);
    j++;
}

// 示例 do-while 循环
int k = 0;
do {
    System.out.println("k = " + k);
    k++;
} while (k < 5);
```
