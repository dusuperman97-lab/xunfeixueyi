# 性能调优

## 一、核心知识讲解

### 1.1 自底向上方法

*   **自底向上方法**：在不同平台上进行应用性能调优时，性能专家常用自底向上的方法。这种方法也适用于将应用迁移到其他操作系统上时改善性能。

### 1.2 USE 方法

*   **USE 方法**：这是一种用于分析定位性能问题的方法，通过检查各类资源的使用率和饱和度来探寻可能存在的性能瓶颈。

### 1.3 系统化过程

*   **系统化过程**：性能调优包括评估问题、测量当前性能、识别系统瓶颈或关键部分、修改该部分以消除瓶颈，然后再次测量性能以查看修改是否带来了改善。这个过程是一个质量保证过程的实例。
