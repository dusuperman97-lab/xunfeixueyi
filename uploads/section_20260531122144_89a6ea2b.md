# Spring Boot快速入门

## 一、核心知识讲解

### 1.1 什么是Spring Boot

*   **定义**：Spring Boot 是一个基于 Java 的框架，用于简化新 Spring 应用程序的初始设置和开发过程。
*   **特性**：它提供了自动配置、起步依赖（starter dependencies）、生产就绪功能等，使开发者能够快速构建独立的、生产级别的应用程序。

### 1.2 Spring Boot的优势

*   **简化配置**：通过自动配置大大减少了传统的 XML 配置文件的需求。
*   **起步依赖**：引入了起步依赖的概念，使得添加常用库变得非常简单。
*   **嵌入式服务器**：支持Tomcat, Jetty, Undertow等嵌入式服务器，无需额外安装即可运行Web应用。
*   **健康检查**：内置了多种健康检查端点，便于监控应用状态。

### 1.3 开发环境搭建

*   **JDK**：确保安装了Java Development Kit (JDK)，推荐使用版本8或更高。
*   **IDE**：建议使用IntelliJ IDEA或者Eclipse作为开发工具。
*   **Maven/Gradle**：项目构建工具，用来管理依赖和构建过程。

## 二、详细示例 / 案例分析

### 2.1 创建第一个Spring Boot应用

*   **步骤1**：访问 https://start.spring.io/ ，选择合适的项目类型、语言及依赖项，点击生成按钮下载项目压缩包。
*   **步骤2**：解压后导入到IDE中，打开`pom.xml`文件查看已添加的依赖。
*   **步骤3**：在`src/main/java/com/example/demo/DemoApplication.java`中找到主类，并运行其main方法启动应用。
*   **步骤4**：浏览器访问 http://localhost:8080/ 可以看到默认欢迎页面。

```java
@SpringBootApplication // 标记这是一个Spring Boot应用
public class DemoApplication {
    public static void main(String[] args) {
        SpringApplication.run(DemoApplication.class, args); // 启动应用
    }
}
```

### 2.2 添加RESTful API

*   **创建控制器**：新建一个名为`HelloController`的类，在其中编写处理HTTP请求的方法。
*   **测试API**：使用Postman或其他工具发送GET请求至 http://localhost:8080/hello ，将返回'Hello, World!'字符串。

```java
@RestController
public class HelloController {
    @GetMapping("/hello")
    public String sayHello() {
        return "Hello, World!";
    }
}
```
