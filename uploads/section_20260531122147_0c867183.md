# 全局异常与统一响应

## 一、核心知识讲解

### 1.1 全局异常处理概述

*   **全局异常处理**：在Spring Boot应用中，通过全局异常处理器可以捕获并处理所有未被捕获的异常，从而提供一个统一的异常处理机制。
*   **@ControllerAdvice**：该注解用于定义全局异常处理器类，可以处理整个应用程序中的异常。
*   **@ExceptionHandler**：该注解用于方法上，指定该方法处理特定类型的异常。

### 1.2 统一响应格式

*   **统一响应**：为了保证API的一致性和可维护性，通常需要定义一个统一的响应格式，包括状态码、消息和数据等。
*   **ResponseEntity**：Spring框架提供的一个类，用于构建HTTP响应，可以方便地设置响应的状态码、头信息和响应体。

### 1.3 实现全局异常处理

*   **创建全局异常处理器类**：使用`@ControllerAdvice`注解定义一个全局异常处理器类，并在其中定义多个`@ExceptionHandler`方法来处理不同类型的异常。
*   **自定义异常类**：根据业务需求，可以自定义一些异常类，以便在代码中抛出更具描述性的异常。

## 二、详细示例 / 案例分析

### 2.1 创建全局异常处理器

假设我们需要创建一个全局异常处理器来处理常见的异常类型，并返回统一的响应格式。

1. 创建全局异常处理器类：

```java
@ControllerAdvice
public class GlobalExceptionHandler {

    @ExceptionHandler(Exception.class)
    public ResponseEntity<ErrorResponse> handleException(Exception e) {
        ErrorResponse error = new ErrorResponse(HttpStatus.INTERNAL_SERVER_ERROR, e.getMessage());
        return new ResponseEntity<>(error, HttpStatus.INTERNAL_SERVER_ERROR);
    }

    @ExceptionHandler(ResourceNotFoundException.class)
    public ResponseEntity<ErrorResponse> handleResourceNotFoundException(ResourceNotFoundException e) {
        ErrorResponse error = new ErrorResponse(HttpStatus.NOT_FOUND, e.getMessage());
        return new ResponseEntity<>(error, HttpStatus.NOT_FOUND);
    }
}
```

2. 定义统一响应格式：

```java
public class ErrorResponse {
    private int status;
    private String message;

    // 构造函数、getter和setter省略
}
```

3. 自定义异常类：

```java
public class ResourceNotFoundException extends RuntimeException {
    public ResourceNotFoundException(String message) {
        super(message);
    }
}
```

### 2.2 使用全局异常处理器

*   在控制器中抛出自定义异常：

```java
@GetMapping("/user/{id}")
public User getUser(@PathVariable Long id) {
    if (id == null || id <= 0) {
        throw new ResourceNotFoundException("User not found with id: " + id);
    }
    // 查询用户逻辑
}
```

*   当请求的ID不合法时，会触发`ResourceNotFoundException`异常，全局异常处理器将捕获该异常并返回统一的响应格式。
