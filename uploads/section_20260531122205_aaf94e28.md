# 变量与数据类型

## 一、核心知识讲解
### 1.1 数据类型的定义与分类
*   **变量**：在编程中，变量是一种存储数据的容器。每个变量都有一个特定的数据类型，它决定了变量可以存储什么样的值以及如何解释这些值。
*   **基本数据类型**：Java中的基本数据类型包括整型（如`int`）、浮点型（如`float`和`double`）、字符型（`char`）和布尔型（`boolean`）。这些类型直接由语言支持，并且有固定的内存占用。
*   **引用数据类型**：除了基本数据类型之外，Java还提供了引用数据类型，例如类、接口、数组等。它们是用户自定义的数据结构，用来创建更复杂的数据表示。
*   **字面量**：字面量是直接出现在代码中的固定值，比如数字`123`或字符串`"hello"`。
*   **类型转换**：当需要将一种数据类型的数据赋给另一种数据类型时，可能需要进行类型转换。这可以是隐式的自动转换，也可以是显式的强制转换。

## 二、详细示例与案例
### 2.1 应用场景
在实际开发中，我们使用不同的数据类型来处理各种信息。例如，在电商系统中，商品的价格通常使用`double`类型来表示，因为价格往往包含小数；用户的姓名则可以用`String`类型来保存。
### 2.2 代码示例
```java
public class Example {
    public static void main(String[] args) {
        int age = 25; // 定义一个整型变量age并初始化为25
        double price = 9.99; // 定义一个双精度浮点型变量price并初始化为9.99
        char initial = 'J'; // 定义一个字符型变量initial并初始化为'J'
        boolean isStudent = true; // 定义一个布尔型变量isStudent并初始化为true
        System.out.println("Age: " + age);
        System.out.println("Price: " + price);
        System.out.println("Initial: " + initial);
        System.out.println("Is a student: " + isStudent);
    }
}
```

## 四、常见误区
### 4.1 易错点
*   **错误表现**：初学者可能会混淆不同数据类型的用途，或者不正确地进行类型转换。
*   **原因**：缺乏对数据类型特性的深入理解。
*   **正确做法**：应当根据数据的实际意义选择合适的数据类型，并遵循类型转换规则。
*   **避免方法**：多练习不同类型的操作，查阅官方文档加深理解。
