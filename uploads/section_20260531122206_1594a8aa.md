# 数组与集合

## 一、核心知识讲解
### 1.1 数组的概念
*   **数组**：是一种有序的数据结构，它具有固定长度和快速随机访问的特点。数组的内存是连续分配的，通过索引可以直接访问任何元素。数组一旦创建，其大小就不能再改变。
*   **适用场景**：数组适用于需要频繁访问特定元素、长度已知且不会变化的场景，例如存储静态的配置信息或者表示固定大小的表格数据。

## 二、详细示例与案例
### 2.1 应用场景
在实际开发中，数组常用于处理固定大小的数据集，如一周的天气数据。由于数组的固定长度特性，可以高效地存储这些数据，并且可以通过索引快速访问。
### 2.2 代码示例
```java
// 声明一个整型数组并初始化
int[] scores = {89, 79, 76};

// 计算平均分
int sum = 0;
double avg;
for (int i = 0; i < scores.length; i++) {
    sum += scores[i];
}
avg = sum / scores.length;
```

## 三、现状分析
### 3.1 技术层面
随着Java的发展，集合框架提供了更灵活的数据结构来替代传统数组。集合（如List、Set）不仅支持动态增删操作，还具备更高的抽象层次，使得数据处理更加方便。

## 四、常见误区
### 4.1 易错点
*   **错误表现**：使用数组时，如果尝试访问超出数组长度的索引，会抛出`ArrayIndexOutOfBoundsException`异常。
*   **原因**：数组的长度是固定的，当试图访问不存在的索引时，就会发生越界。
*   **正确做法**：在访问数组元素前，应先检查索引是否在有效范围内。
*   **避免方法**：使用增强for循环遍历数组，这样可以避免手动管理索引带来的风险。
