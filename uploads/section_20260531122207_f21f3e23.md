# 方法与函数

## 一、核心知识讲解（25%）
### 1.1 函数的基本概念
*   **函数**：在Java中，也称为方法，是一段具有特定功能的代码块，可以被多次调用执行。函数的主要作用是封装代码，提高代码的复用性和可读性。
*   **访问修饰符**：用于控制类、变量、方法和构造方法的访问权限。如`public`对所有类可见，`private`只在同一类内可见，`protected`对同一包内的类和所有子类可见。
*   **返回值类型**：函数可以有返回值也可以没有。有返回值的函数使用`return`语句返回结果，而无返回值的函数则使用`void`作为返回值类型。
*   **参数列表**：表示函数中的不确定因素，包括形参（形式上的参数，没有具体值）和实参（实际传递给函数的值）。多个参数之间通过逗号分隔。
*   **函数调用**：自定义函数需要经过调用才能执行。调用时需提供必要的实参，并根据函数是否带有返回值来决定如何处理返回的数据。

## 二、详细示例与案例（25%）
### 2.1 应用场景
以一个简单的打印分割线的函数为例，我们可以看到函数如何接受参数并执行相应的操作。例如，定义一个名为`printLine`的函数，它接受两个参数：一个是整数类型的`n`代表要打印的符号数量，另一个是字符串类型的`str`代表要打印的符号。通过循环结构输出指定数量的字符。
### 2.2 代码示例
```java
public static void printLine(int n, String str) {
    for (int i = 1; i <= n; i++) {
        System.out.print(str);
    }
    System.out.println();
}
// 调用示例
printLine(10, "-"); // 输出：----------
```

## 三、现状分析（20%）
### 3.1 技术层面
随着面向对象编程的发展，函数或方法成为程序设计中不可或缺的一部分。它们不仅能够帮助程序员更好地组织代码，还支持代码重用，提高了开发效率。在现代软件开发中，合理地设计和使用函数是编写高质量代码的关键。

## 四、常见误区（10%）
### 4.1 易错点
*   **错误表现**：忘记为带形参的函数提供实参，导致编译错误。
*   **原因**：对形参和实参的概念理解不清。
*   **正确做法**：确保每次调用带参数的函数时都提供正确的实参。
*   **避免方法**：仔细检查函数声明和调用处的参数列表是否匹配。
