## 一、核心知识讲解（25%）
### 1.1 游戏主界面结构解析
*   **顶部状态栏**：显示当前段位（如倔强青铜Ⅲ）、金币/点券余额、好友在线状态及系统通知图标。该区域是玩家实时掌握资源与社交动态的核心入口，左侧段位标识采用动态徽章设计，点击可查看赛季历程；右侧消息气泡支持一键跳转至私信或战队公告，确保信息触达零延迟。状态栏还集成快捷设置按钮，允许快速调整音效、画质与匹配偏好，显著降低新手在多任务切换中的认知负荷。

*   **中央对战区域**：以全息投影式3D渲染呈现英雄选择界面，包含禁用/选用英雄池、阵容预览框及实时BP（Ban/Pick）倒计时。该区域采用物理引擎模拟光照反射，英雄模型随鼠标悬停自动旋转展示技能特效，帮助新手直观理解角色定位（如法师/坦克/射手）。底部血条与技能栏采用高对比度色块设计，红色血条宽度动态映射生命值，蓝色法力条同步显示技能冷却进度，确保战场决策信息秒级响应。

*   **底部功能导航栏**：由“首页”“赛事”“社区”“背包”“我的”五大图标构成，采用底部标签栏（Bottom Tab Bar）交互范式。其中“首页”默认加载个性化推荐内容（如新手引导任务、限时活动入口）；“背包”集成皮肤/铭文/英雄管理，支持拖拽式铭文搭配预设保存；“我的”提供成就系统与观战回放功能，新玩家可通过观看高手录像学习走位技巧与技能连招节奏。

### 2.2 英雄技能连招代码化演示（以李白为例）
```python
# 模拟李白经典连招：将进酒→神来之笔→青莲剑歌→普通攻击
# 注：实际游戏中需根据敌方位置动态调整技能释放顺序

class LiBaiCombo:
    def __init__(self):
        self.skill_cooldown = {"jiu": 12.0, "shen": 8.0, "qing": 35.0}  # 技能冷却时间（秒）
        self.energy_cost = {"jiu": 50, "shen": 40, "qing": 150}      # 法力消耗
        self.range = {"jiu": 400, "shen": 300, "qing": 500}         # 技能作用半径
    
    def execute_combo(self, enemy_position, hero_position):
        """
        执行连招逻辑：
        1. 使用将进酒突进至敌方身边（需满足距离≤400）
        2. 立即释放神来之笔标记目标（需在将进酒结束瞬间触发）
        3. 当标记持续3秒后，开启青莲剑歌造成范围眩晕
        4. 补充普攻触发被动“侠客行”额外伤害
        """
        distance = self.calculate_distance(enemy_position, hero_position)
        if distance <= self.range["jiu"]:
            print("✅ 步骤1：使用将进酒突进！")
            # 模拟突进后位置更新
            new_position = self.move_toward(enemy_position, hero_position, self.range["jiu"])
            
            # 神来之笔需在突进结束帧释放，否则标记失效
            print("✅ 步骤2：神来之笔标记成功！")
            
            # 青莲剑歌需等待标记持续满3秒，期间可移动调整站位
            import time
            time.sleep(3)  # 模拟等待标记时间
            print("✅ 步骤3：青莲剑歌释放，范围眩晕生效！")
            
            # 普攻触发被动，每第四次攻击造成额外真实伤害
            for i in range(4):
                if i == 3:
                    print("💥 步骤4：第四次普攻触发侠客行，造成200点真实伤害！")
                else:
                    print(f"⚔️  第{i+1}次普攻")
        else:
            print("❌ 距离过远，无法启动连招，请先接近敌人！")
    
    def calculate_distance(self, p1, p2):
        return ((p1[0]-p2[0])**2 + (p1[1]-p2[1])**2)**0.5
    
    def move_toward(self, target, current, max_distance):
        # 简化版向量移动计算
        dx = target[0] - current[0]
        dy = target[1] - current[1]
        distance = (dx**2 + dy**2)**0.5
        if distance > max_distance:
            dx, dy = dx/distance*max_distance, dy/distance*max_distance
        return (current[0]+dx, current[1]+dy)

# 测试用例：敌方位于(1000,500)，我方初始位置(500,500)
combo = LiBaiCombo()
combo.execute_combo(enemy_position=(1000, 500), hero_position=(500, 500))
```

## 四、常见误区（10%）
### 4.1 易错点
新手常误将右上角技能图标当作固定按键，导致团战中频繁误触闪现而非大招。根本原因在于未理解技能栏的“动态覆盖逻辑”：当英雄装备“闪现”召唤师技能时，其图标会永久占据右上角位置，而原大招图标移至右侧第二格，需滑动技能栏才能触发。正确做法是进入设置→操作设置→启用“技能轮盘”模式，此时大招将以环形菜单形式悬浮于屏幕右侧，手指顺时针滑动即可精准释放。避免方法是在训练营反复练习“闪现+大招”组合技，录制操作轨迹并对比职业选手录像，重点观察技能图标位置变化规律。
