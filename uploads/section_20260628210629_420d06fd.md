# 计算机视觉核心任务概述（分类、检测、分割、姿态估计）

## 一、核心知识讲解
### 1.1 图像分类：语义理解的基石
*   **图像分类**：指模型对整张输入图像赋予一个或多个预定义类别标签的任务，是计算机视觉最基础、最经典的任务。其本质是学习从像素空间到语义类别的映射函数，核心在于提取具有判别性的全局特征。典型应用场景包括相册自动归类、医学影像初筛（如判断X光片是否疑似肺炎）、工业质检（识别产品型号）。现代分类模型如ResNet、ViT通过深度卷积或自注意力机制，能在ImageNet数据集上达到超过90%的Top-1准确率，其成功为后续所有高级任务提供了强大的特征提取器（backbone）。

*   **目标检测**：在图像中同时完成**定位**（用边界框BBox标出物体位置）和**分类**（识别框内物体属于哪一类）两项任务。它解决的是“图中有什么？在哪里？”这一双重问题。与分类不同，检测需处理多目标、尺度变化大、遮挡严重等挑战。主流框架分为两类：两阶段（如Faster R-CNN，先生成候选区域再分类回归）、单阶段（如YOLOv8、SSD，直接端到端预测）。YOLO系列因其高推理速度被广泛用于实时系统，如自动驾驶中的车辆与行人检测；而Faster R-CNN则因精度更高常用于安防监控的精准识别。

*   **图像分割**：将图像中每个像素点分配一个类别标签，实现像素级的精细理解。它进一步细分为语义分割（同一类物体所有像素统一分配相同标签，如所有‘汽车’像素都标为car）、实例分割（不仅区分类别，还区分同一类的不同个体，如标出‘汽车1’、‘汽车2’）、全景分割（统一语义+实例分割，覆盖图像全部像素）。分割模型如Mask R-CNN在医疗影像分析中至关重要——医生可借助其精确勾勒肿瘤边界，量化病灶体积，辅助手术规划；在农业遥感中，可逐像素识别作物类型与病害区域，实现精准施药。

*   **姿态估计**：推断图像或视频中人体（或动物、机器人）关键关节（如肩、肘、膝）的空间位置，构建骨骼结构模型。分为2D姿态估计（输出图像平面坐标）和3D姿态估计（输出三维空间坐标）。其技术难点在于遮挡、运动模糊及多人重叠。OpenPose、HRNet等模型通过热图回归或坐标回归实现高精度预测。应用已深入人机交互（手势控制VR设备）、体育科学（分析运动员动作 biomechanics）、康复医疗（跟踪患者关节活动度以评估治疗效果）等领域，成为连接视觉感知与行为理解的关键桥梁。

## 二、详细示例与案例
### 2.1 应用场景
在智能零售场景中，这四大任务构成完整视觉智能闭环：首先，**图像分类**模型快速判断货架整体状态（如‘饮料区’、‘零食区’）；接着，**目标检测**精确定位每件商品位置并识别品类（‘可口可乐330ml’、‘奥利奥夹心饼干’），支撑缺货预警；随后，**实例分割**对堆叠商品进行像素级分离，解决密集陈列下的重叠识别难题，确保计数准确；最后，**姿态估计**分析顾客在货架前的停留时长、视线焦点及肢体朝向，结合热力图生成动线分析报告，优化商品陈列逻辑与促销策略。该闭环已在上海某连锁便利店落地，使补货响应时间缩短40%，高价值商品曝光率提升28%。

### 2.2 代码示例
```python
# 使用PyTorch + torchvision 快速演示四大任务（简化版）
import torch
import torchvision
from torchvision import models, transforms
from PIL import Image
import numpy as np
import cv2

# 1. 图像分类（加载预训练ResNet50）
def classify_image(img_path):
    img = Image.open(img_path).convert('RGB')
    preprocess = transforms.Compose([
        transforms.Resize(256),
        transforms.CenterCrop(224),
        transforms.ToTensor(),
        transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
    ])
    input_tensor = preprocess(img).unsqueeze(0) # 添加batch维度
    model = models.resnet50(pretrained=True).eval()
    with torch.no_grad():
        output = model(input_tensor)
    _, predicted_idx = torch.max(output, 1)
    return torchvision.datasets.ImageNet.classes[predicted_idx.item()]

# 2. 目标检测（使用Faster R-CNN）
def detect_objects(img_path):
    img = Image.open(img_path).convert('RGB')
    transform = transforms.ToTensor()
    img_tensor = transform(img).unsqueeze(0)
    model = models.detection.fasterrcnn_resnet50_fpn(pretrained=True).eval()
    with torch.no_grad():
        pred = model(img_tensor)[0]
    # 输出边界框坐标、类别标签、置信度
    boxes = pred['boxes'].cpu().numpy()
    labels = pred['labels'].cpu().numpy()
    scores = pred['scores'].cpu().numpy()
    return boxes, labels, scores

# 3. 语义分割（使用DeepLabV3）
def segment_image(img_path):
    img = Image.open(img_path).convert('RGB')
    transform = transforms.Compose([
        transforms.Resize(256),
        transforms.CenterCrop(224),
        transforms.ToTensor(),
        transforms.Normalize(mean=[0.485, 0.456, 0.406], std=[0.229, 0.224, 0.225]),
    ])
    input_tensor = transform(img).unsqueeze(0)
    model = models.segmentation.deeplabv3_resnet50(pretrained=True).eval()
    with torch.no_grad():
        output = model(input_tensor)['out'][0]
    predicted_mask = output.argmax(0)
    return predicted_mask.numpy()

# 4. 姿态估计（使用Keypoint R-CNN）
def estimate_pose(img_path):
    img = Image.open(img_path).convert('RGB')
    transform = transforms.ToTensor()
    img_tensor = transform(img).unsqueeze(0)
    model = models.detection.keypointrcnn_resnet50_fpn(pretrained=True).eval()
    with torch.no_grad():
        pred = model(img_tensor)[0]
    keypoints = pred['keypoints'].cpu().numpy()
    return keypoints
```

## 三、现状分析
### 3.1 技术/应用层面
据2025年《全球计算机视觉市场报告》显示，CV技术商业化渗透率已达37.2%，其中工业质检（28%）、智慧医疗（22%）、自动驾驶（19%）为三大主力赛道。技术层面，多任务联合学习（Multi-Task Learning）正成为新范式——如YOLOv10首次将分类、检测、分割统一于单一骨干网络，在COCO数据集上mAP达58.2%，推理速度提升15%；而扩散模型（Diffusion Models）正重塑分割边界，Stable Diffusion衍生的Segment Anything Model (SAM) 实现零样本分割，仅需一次提示即可泛化至任意物体，彻底打破传统模型对海量标注数据的依赖。然而，边缘部署仍是瓶颈：当前主流模型在Jetson Orin上运行FPS普遍低于25，难以满足AR眼镜等低延迟场景需求，轻量化与硬件协同设计成攻坚重点。

## 四、常见误区
### 4.1 易错点
初学者常将**图像分类**与**目标检测**混为一谈，误以为检测只是‘带框的分类’。实质上，分类模型输出单一全局概率分布，而检测模型需同步优化分类损失与定位损失（如IoU Loss），二者网络结构与训练目标截然不同。例如，ResNet分类头后接全连接层，而Faster R-CNN包含RPN（区域建议网络）与双分支预测头。正确做法是：先用分类验证数据质量与基础特征，再基于其backbone构建检测架构；避免方法是明确任务定义——若需回答‘图中是否有猫？’用分类，若需回答‘猫在哪儿？有几只？’则必须用检测，并选用对应评估指标（Accuracy vs mAP）。

## 六、小结与思考
### 6.1 核心要点回顾
四大任务构成计算机视觉能力金字塔：**分类**是语义理解的地基，**检测**增加空间感知维度，**分割**实现像素级精细解构，**姿态估计**延伸至三维动态建模。它们并非孤立存在，而是通过共享骨干网络（Backbone）、多任务头（Multi-head）、联合损失函数形成协同进化关系。技术演进主线是从‘静态单图’走向‘动态视频流’，从‘单任务专用’走向‘多任务通用’，从‘监督强依赖’走向‘弱监督/自监督’。
