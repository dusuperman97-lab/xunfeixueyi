# 第一个Java程序：Hello World

## 一、核心知识讲解
### 1.1 Java程序执行流程与JVM机制
*   **Java虚拟机（JVM）**：是Java实现“一次编写，到处运行”的核心组件，它是一个抽象的计算机器，负责加载.class字节码文件、执行指令、管理内存（堆、栈、方法区）、进行垃圾回收以及提供安全验证机制。当你运行`java HelloWorld`时，JVM会启动并加载编译后的字节码，通过解释器或即时编译器（JIT）将其转换为本地机器指令执行。JVM屏蔽了底层操作系统差异，使得同一份字节码可在Windows、Linux或macOS上无缝运行，这是Java跨平台能力的根本保障。

*   **编译与运行分离模型**：Java采用“先编译、后运行”的两阶段模型。源代码（.java）必须先通过`javac`编译器生成平台无关的字节码（.class），再由JVM加载执行。这与Python等解释型语言（源码直译）或C/C++等纯编译型语言（源码直接生成机器码）形成鲜明对比。该设计兼顾了安全性（字节码可校验）与性能（JIT动态优化），也便于实现类加载、热部署等高级特性。

*   **public static void main(String[] args)方法签名**：这是Java应用程序的唯一入口点，其每个修饰符和参数都具有严格语义。`public`确保该方法可被JVM外部调用；`static`表示无需创建类实例即可执行，符合启动时无对象上下文的场景；`void`说明不返回任何值；`main`是JVM约定的固定方法名；`String[] args`是字符串数组，用于接收命令行参数，如`java HelloWorld arg1 arg2`中，args[0]为"arg1"，args[1]为"arg2"。任何缺失或拼写错误都会导致`NoSuchMethodError`。

### 2.2 代码示例
```java
/**
 * 第一个Java程序：Hello World
 * 本示例完整展示标准结构、注释规范与扩展可能性
 */
public class HelloWorld {
    
    // 静态代码块：在类加载时执行一次，可用于初始化静态资源
    static {
        System.out.println("【静态初始化】HelloWorld类正在加载...");
    }
    
    // 实例代码块：每次创建对象时执行，此处未使用但保留结构示意
    {
        System.out.println("【实例初始化】新HelloWorld对象已创建");
    }
    
    // 主方法：程序唯一入口点
    public static void main(String[] args) {
        // 1. 基础输出
        System.out.println("Hello, World!");
        
        // 2. 命令行参数处理（演示args用法）
        if (args.length > 0) {
            System.out.print("你输入的参数有：");
            for (int i = 0; i < args.length; i++) {
                System.out.print(args[i]);
                if (i < args.length - 1) System.out.print(", ");
            }
            System.out.println();
        } else {
            System.out.println("提示：可尝试 java HelloWorld 张三 李四 运行带参数版本");
        }
        
        // 3. 字符串拼接与格式化输出
        String name = "Java初学者";
        int year = 2024;
        System.out.printf("欢迎%s加入Java世界！当前年份：%d%n", name, year);
        
        // 4. 异常处理演示（增强健壮性意识）
        try {
            // 模拟可能出错的操作
            String greeting = getGreeting();
            System.out.println(greeting);
        } catch (RuntimeException e) {
            System.err.println("发生运行时异常：" + e.getMessage());
        }
    }
    
    // 辅助方法：演示方法定义与调用
    private static String getGreeting() {
        return "你好，Java世界！";
    }
}
```

## 四、常见误区
### 4.1 文件名与类名不匹配
错误表现为编译时报错`error: class HelloWorld is public, should be declared in a file named HelloWorld.java`。根本原因是Java规定：若类声明为`public`，则源文件名必须与类名完全一致（包括大小写），且一个.java文件只能有一个public类。正确做法是严格遵循命名规范，将文件保存为`HelloWorld.java`；若需多类共存，可将非public类（如工具类）置于同一文件，但主入口类必须独占文件。避免方法是在IDE中启用“Save actions”，设置自动同步文件名与类名，并开启编译器实时检查。
