# 项目实践教学平台 (Project Practical Teaching Platform)

## 项目简介

本项目是一个基于 **AI 大模型**的智能教学一体化平台，面向高校师生提供课程管理、AI 对话学习、数字人教师、课程自动生成、知识库检索、智能考试、PPT 生成、思维导图等全方位教学辅助功能。系统采用前后端分离架构，包含 **管理端**（教师/管理员）和 **学生端** 两大角色入口。

## 核心功能模块

### 1. 用户与认证系统
- 注册 / 登录 / 密码找回
- 管理员与学生的角色分离
- **学生画像引导**：首次登录时引导填写学习偏好、基础水平等，用于个性化推荐
- 个人信息编辑、密码修改

### 2. AI 对话学习助手 (`/student/chat`)
- 基于大模型的对话式学习助手
- **多轮对话记忆**，支持会话切换与历史回顾
- **多模态支持**：可上传图片进行提问分析
- **代码辅助**：支持编程问题的智能解答
- **积分消费**：AI 对话消耗积分
- **工具调用**：AI 可调用联网搜索、B站视频搜索、图片搜索等工具获取实时信息

### 3. 课程自动生成 (`/student/course`)
- **AI 一键生成课程**：输入课程主题，自动生成课程大纲、章节内容
- **内容校验**：AI Agent 自动对生成的内容进行事实核查和质量验证
- 课程列表展示与课程管理
- 课程学习工作区（全屏沉浸式学习）

### 4. 数字人教师 (`/student/digitalHuman`)
- 3D 数字人形象作为虚拟教师
- 全屏交互界面，沉浸式学习体验
- AI 驱动的对话式教学

### 5. 知识库与 RAG 检索 (`/student/knowledge`)
- 知识库创建与管理
- 文档上传与管理
- **RAG（检索增强生成）**：基于知识库文档进行智能问答

### 6. 智能考试系统 (`/student/QuestionBank`)
- 题库管理：单选题、多选题、判断题等
- AI 自动生成试题
- 考试答题记录与评估
- 章节测试总结

### 7. PPT 智能生成 (`/student/PPTAgent`)
- 输入主题自动生成 PPT 课件
- 支持下载导出

### 8. 思维导图 / 学习辅导 (`/student/tutoring`)
- AI 生成思维导图辅助知识梳理
- 知识点关联可视化

### 9. 学习路径 (`/student/path`)
- 个性化学习路径推荐
- 视频学习资源整合

### 10. 学习资源中心 (`/student/resources`)
- 学习资料搜索与浏览
- 资源收藏管理

### 11. 会员与积分系统 (`/student/membership`)
- 积分余额查看
- 积分交易记录
- 积分消费（AI 功能消耗）

### 12. 学习评估 (`/student/evaluation`)

- 学习时长记录

## 快速启动

### 环境要求
- JDK 17+
- Maven 3.8+
- Node.js 18+
- MySQL 8.0+
- （可选）Neo4j 知识图谱

### 后端启动

1. 创建 MySQL 数据库并执行 `sql/` 目录下的初始化脚本
2. 配置 `application-secret.yml` 中的数据库连接、OSS、AI 服务等密钥
3. 启动 Spring Boot 应用：
```bash
mvn spring-boot:run
```

### 前端启动

```bash
cd web
npm install
npm run dev          # 开发环境
npm run build-prod   # 生产构建
```

## 智能体应用价值

### 问题溯源：高等教育学习的核心痛点

在高等教育学习过程中，学生普遍面临三大结构性困境：

1. **资源过载与匹配失准**：不同专业、不同学历层次的学生面对海量课程资料、学术文献、视频教程时，缺乏有效手段快速筛选契合自身进度与能力的资源，"信息过载"反而降低了学习效率
2. **学习指导的"一刀切"困境**：课堂集体讲授模式无法兼顾每位学生的学习节奏与认知特点，基础薄弱的学生跟不上、学有余力的学生"吃不饱"，知识掌握和能力提升上存在显著个体差距
3. **智能化工具的能力断层**：传统学习管理系统和基础 AI 辅助工具，因缺乏多模态生成、多智能体协同等前沿技术支撑，仅能提供静态的内容展示和关键词检索，无法实现主动感知、精准匹配、个性化引导

基于以上痛点，本平台构建 **多智能体协同教学系统**，以人工智能、计算机、电子信息等专业课程为切入点，在下列维度实现"因材施教"的数字化落地。

### 一、个性化资源精准匹配 — 从"人找资源"到"资源找人"

针对"资源繁杂无序、难以精准匹配自身需求"的核心问题，平台构建了 **资源推送智能体**，实现主动感知式的资源服务：

- **上下文感知**：智能体自动读取学生当前课程、章节、小节信息，基于学习进度而非泛化关键词推送资源，确保每条内容"应景"
- **跨平台聚合搜索**：单次推送同步检索 B 站、抖音、知乎、CSDN、Tavily 学术搜索、百度图片等多个平台，打破数据孤岛，将分散在各处的优质教育资源汇聚为统一视图
- **多模态资源覆盖**：同步推送视频课程、教材资料、学术文献三类内容，分别对应"观看学习→系统阅读→深度研究"的递进式学习路径，满足不同场景下的学习需求
- **增量式资源积累**：每次推送追加新资源而非覆盖旧有内容，学生的个人资源库持续生长，形成可回溯、可对比的长期学习资料体系
- **价值体现**：将学生从"不知道该搜什么、不知道怎么搜、搜了也找不到"的三重困境中解放出来，资源获取时间从平均 15 分钟的搜索筛选缩短为一次刷新推送，学生将宝贵时间还给学习本身

### 二、课程内容自动化生成与校验 — 破解"个性化内容匮乏"难题

不同学生需要不同深度和广度的学习材料，但教师难以逐一满足。平台的 **课程生成智能体** 通过多 Agent 协作流水线解决这一矛盾：

- **五阶段协作生成**：大纲规划 Agent → 内容撰写 Agent → 资源检索 Agent → 质量校验 Agent → 课件组装 Agent，各智能体分工明确、流水线协作，将一门结构化课程的生产周期从数周压缩至分钟级
- **内容质量保障**：校验 Agent 对 AI 生成内容进行事实核查与准确性评估，自动标注存疑知识点，确保教学内容的学术严肃性——这是教育场景区别于通用 AI 应用的关键能力
- **价值体现**：教师从繁重的内容开发中解放，将精力聚焦于教学设计创新和学生深度互动；同时课程内容可基于学生反馈持续迭代优化，实现"越用越好"的良性循环

### 三、多模态智能辅导 — 让每位学生拥有专属"AI 助教"

课堂统一讲授无法顾及个体差异，而研究生助教资源有限。平台 **对话学习智能体** 提供 7×24 小时的个性化辅导：

- **自主工具调用能力**：Agent 不是被动回答的聊天机器人，而是能主动调用联网搜索、B 站视频搜索、图片搜索等外部工具的自主智能体，将最新的网络知识实时引入对话
- **多轮深度对话**：基于会话记忆管理，Agent 能理解前后文语境和学生的学习轨迹，提供连贯的、逐步深入的辅导，而非孤立的一问一答
- **多模态交互**：支持图片上传分析——学生可拍照上传公式推导、代码片段、电路图、实验数据等进行提问，Agent 结合视觉理解给出针对性解答
- **代码辅助开发**：针对人工智能、计算机等专业课程，Agent 提供代码解读、Bug 定位、算法优化建议和编程最佳实践，将"学"与"练"无缝衔接
- **价值体现**：等效于为每位学生配备一名了解其学习背景的私人助教，从根源上缓解高校师生比不足、辅导资源紧缺的痛点

### 四、知识库驱动的精准问答 — 让私有知识"活"起来

通用大模型对垂直学科的回答常有"幻觉"。平台 **RAG 知识库智能体** 基于检索增强生成技术，将教师提供的课件、教材、论文转化为可靠的知识源：

- **文档即语料库**：上传教学文档后自动切片、向量化索引，无需微调模型即可使 AI "学会"课程专属知识
- **溯源式回答**：每条回答附带原文引用出处，学生可追溯验证，避免 AI "一本正经胡说八道"的风险，这在学术严谨性要求高的高等教育场景中至关重要
- **知识图谱联动**：结合 Neo4j 图数据库，将碎片化知识点关联为可视化知识网络，帮助学生建立系统化的认知结构而非孤立记忆
- **价值体现**：私有知识问答准确率显著高于纯大模型回答，使 AI 辅助真正适用于对精度要求极高的专业课程教学

### 五、多智能体协同 — 从单一工具到协作生态

本平台区别于功能堆砌型产品的核心壁垒，在于智能体间的 **深度协作能力**：

| 协作场景 | 参与智能体 | 协作产出 | 对应解决的痛点 |
|----------|-----------|----------|--------------|
| 课程建设 | 大纲 Agent + 内容 Agent + 资源 Agent + 校验 Agent | 结构化课程 + 多模态资源包 | 个性化内容匮乏 |
| 资源推送 | 搜索 Agent + 图片 Agent + 视频 Agent + 存储 Agent | 带封面的全平台资源库 | 资源繁杂无序 |
| 学习辅导 | 对话 Agent + 知识库 Agent + 搜索 Agent + 代码 Agent | 有据可查的深度答疑 | 缺乏智能指导 |
| 考试评估 | 出题 Agent + 知识图谱 Agent + 评估 Agent | 按知识点覆盖的智能组卷 | 个体掌握差异 |
| 学生画像 | 行为分析 Agent + 推荐 Agent + 路径规划 Agent | 自适应学习路径 | 无法兼顾个体 |

### 六、教育数字化的深层价值

- **真正实现"因材施教"**：学生画像智能体持续学习每位学生的知识薄弱点、学习偏好和进度节奏，驱动所有上层智能体进行个性化调整——课程内容适配难度、推送资源匹配水平、辅导对话贴合背景，将因材施教从教育理念变为可运行的软件系统
- **促进教育公平**：优质教学资源与 AI 辅导能力不受地域、师资、时间的物理限制，使不同地区、不同层次高校的学生都能获得高质量的智能化学习支持
- **教师角色升级**：将教师从出题、备课、资源搜集等重复性劳动中释放，使其聚焦于教学创新、深度互动和学生高阶思维培养——AI 不是替代教师，而是放大教师的影响力
- **能力可迁移**：多智能体协同架构可横向复用到职业培训、企业内训、K12 教育、终身学习等更多教育场景，具有广泛的社会应用前景

## 开发说明

- 后端接口遵循 RESTful 风格，统一使用 `ResponseVO` 封装返回

- AI 功能使用 `@ConsumePoints` 和 `@TrackAiUsage` 注解进行积分消耗和使用量统计
